# Qist

A dependency-free, client-side IT chargeback and showback dashboard for modeling ITSM costs, SLA credits, asset subscriptions, compliance surcharges, and department ledgers.

## Run Locally

Open `index.html` in a browser. No build step or package install is required.

## What Is Included

- Premium enterprise SaaS UI with responsive sidebar navigation, global search, dark/light mode, dense KPI cards, sparklines, polished tables, badges, and tooltips.
- Settings & Rates panel for departments, headcount, hourly rates, flat fees, priority multipliers, after-hours fees, asset subscriptions, HIPAA/PHI surcharges, e-waste fees, and shared overhead.
- CSV/JSON drag-and-drop ingestion with smart column mapping.
- Calculation engine for ticket labor, tier flat fees, SLA breach credits, sensitivity surcharges, asset subscriptions, and pro-rata overhead.
- Executive overview with KPIs, spend charts, monthly trend, SLA analysis, and resolver utilization.
- Department ledger view for department heads.
- Ticket inspector with department, priority, sensitivity, and search filters.
- Export center for executive PDF, department ledger CSV, and ticket calculation CSV.

## Sample Data

The app loads realistic mock ticket data by default. Additional sample files are in `sample-data/`.
